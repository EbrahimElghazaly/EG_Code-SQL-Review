## 📖 عن المشروع

مراجعة شاملة ومتكاملة لأوامر **SQL Server** مع شرح تفصيلي وأمثلة عملية لكل أمر. تم تصميم الصفحة بشكل تفاعلي وجذاب لتسهيل عملية المراجعة قبل المقابلات أو الاختبارات.

## ✨ المميزات

- ✅ **أكثر من 30 أمر SQL** مغطاة بالشرح والأمثلة
- ✅ **تصميم تفاعلي** مع قائمة جانبية للتنقل السريع
- ✅ **نسخ الأكواد** بنقرة زر واحدة
- ✅ **نموذج تواصل** يعمل عبر Formspree
- ✅ **متجاوب** مع جميع أحجام الشاشات
- ✅ **تلوين الأكواد** (Syntax Highlighting)
- ✅ **دعم اللغة العربية** بشكل كامل

## 📋 قائمة الأوامر المشروحة

| القسم | الأوامر |
|-------|---------|
| **Database Basics** | CREATE DATABASE, CREATE TABLE, INSERT, DELETE, TRUNCATE |
| **Data Manipulation** | UPDATE, SELECT, WHERE, ORDER BY, DISTINCT |
| **Conditions** | BETWEEN, IN, LIKE, CASE, AND, OR, NOT |
| **Aggregation** | GROUP BY, HAVING, COUNT, SUM, AVG, MAX, MIN |
| **Keys & Constraints** | PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, DEFAULT, CONSTRAINT |
| **Joins** | INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN |
| **Advanced** | SUBQUERY, VIEW, CTE, Window Functions, Stored Procedures |
| **SQL Server** | TOP, GETDATE(), @@ROWCOUNT, T-SQL |
